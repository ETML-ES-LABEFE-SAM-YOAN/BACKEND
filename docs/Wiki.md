# Choix technologiques

## Backend
- **Spring Boot 3.2**
    - Pourquoi : Framework moderne, robuste, bien documenté, facilite la création d’API REST.
    - [Documentation officielle](https://spring.io/projects/spring-boot)

- **Java 17**
    - Pourquoi : Version LTS, compatible avec Spring Boot 3.x, nouvelles fonctionnalités utiles.

- **Maven**
    - Pourquoi : Gestionnaire de dépendances standard, facile à utiliser avec Spring Boot.

## Base de données
- **MySQL** Avait déjà Mysql installé suite à un cours de base de données.

## Sécurité
- **Spring Security**
    - Pourquoi : Intégration native avec Spring Boot, gestion facile des rôles et authentification.


## Outils complémentaires
- **Swagger**
    - Pourquoi : Documentation automatique des endpoints REST.
